# 🌸 Scentology - E-Commerce React Application

A luxury perfume e-commerce web application built with **React** and **Bootstrap 5**, featuring a minimalist design, dynamic catalog rendering, interactive quiz, and responsive navigation.

---

## 📌 Features

- **Home Page**: Hero section with dark overlay, luxury typography, and clear Call-to-Action (CTA).
- **Catalog Page**: Dynamic rendering of perfume products using JavaScript array mapping (`.map()`).
- **Interactive Scent Quiz**: Multi-step quiz helping users find their signature fragrance based on state management (`useState`).
- **About Page**: Clean brand storytelling with high-contrast hero typography.
- **Contact Form**: Interactive form with state tracking and JSON data formatting (`JSON.stringify`).
- **Persistent Data**: Local storage implementation (`localStorage`) for saving user preferences and quiz answers.
- **Responsive Layout**: Built with standard Bootstrap 5 layout components (`container`, `row`, `col`, `card`, `navbar`).

---

## 🛠️ Tech Stack & Concepts

- **Frontend**: React.js (Functional Components, Hooks: `useState`, `useEffect`)
- **Styling**: Bootstrap 5 (Native classes) & Custom CSS (`App.css`)
- **Routing**: React Router DOM (`BrowserRouter`, `Routes`, `Route`, `Link`)
- **Data Handling**: Dynamic array manipulation (`.map()`, `.filter()`), JSON parsing/stringifying
